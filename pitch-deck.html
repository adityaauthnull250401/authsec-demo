How it works

One rule, checked on every call

A tool requires a scope list_commits → commits:read
A role grants scopes Reader → commits:read, repo:read
An identity holds a role agent → Reader
Access = the identity carries the scope the tool needs — re-checked on every call. Pull the grant and the next request dies, even on a token that hasn’t expired.
